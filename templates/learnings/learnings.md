# Crew learnings

Findings this repository has already decided about. The reviewer and the security agent
read this file and must not raise anything recorded here again, unless the code changed
such that the reason no longer holds.

Copy this file to `.basivo-crew/learnings.md` in your repo. The follow-up workflow
appends to it when a maintainer dismisses a finding, so it grows on its own — this is
the one piece of state the crew keeps between runs, and it is what stops it from
nagging you about the same thing every week.

## Format

```
- **<finding, in one line>**
  Dismissed by @<who> on <date>, PR #<n>. Reason: <why it is not a defect here>.
```
